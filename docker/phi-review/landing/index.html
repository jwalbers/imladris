imladris-phi · PHI Review Environment

ISOLATED · LOCAL ONLY · NO CLOUD FORWARDING · BESSIE ONLY

This environment is reserved for reviewing identifiable patient DICOM studies — for example, working with a radiologist on anonymization verification before studies are de-identified. Studies loaded here are stored locally on BESSIE only and cannot reach AdvaPACS or any other remote system.

This environment is for

  • Radiologist review of PHI studies
  • Anonymization verification sessions
  • Local DICOM QA before de-identification
  • Direct upload via Orthanc REST API

Never do this here

  • Forward studies to AdvaPACS
  • Forward studies to any cloud PACS
  • Push to GCS or any shared storage
  • Share screen outside secure session
